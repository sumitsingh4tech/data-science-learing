# Data Science Learning

A personal repository for learning and practicing data science concepts, tools, and techniques.

## Overview

This project collects notes, exercises, and small projects as I work through data science topics—from fundamentals to applied machine learning.

## Topics

- Python for data analysis
- NumPy, Pandas, and Matplotlib
- Statistics and probability
- Exploratory data analysis (EDA)
- Machine learning basics
- Jupyter notebooks and workflows

## Getting Started

### Prerequisites

- Python 3.9+
- [pip](https://pip.pypa.io/) or [conda](https://docs.conda.io/)

### Setup

```bash
git clone https://github.com/sumitsingh4tech/data-science-learing.git
cd data-science-learing
python -m venv venv
source venv/bin/activate   # On Windows: venv\Scripts\activate
pip install -r requirements.txt   # when available
```
